# OmniVoice Raycast Integration

These scripts are Raycast Script Commands for the local OmniVoice engine.

Install:

1. Open Raycast Settings.
2. Go to Extensions.
3. Add this folder as a Script Commands directory.
4. Make sure OmniVoice has been launched at least once. The app starts the local engine when needed.

Included commands:

- `OmniVoice Status`: shows engine health.
- `OmniVoice Dashboard`: opens the local engine dashboard.
- `OmniVoice Transcripts`: opens the transcript view endpoint.
- `Start OmniVoice App`: asks the engine to launch the desktop app.

These scripts only talk to the local engine. They do not send transcript data to Raycast or any cloud service.
